# deepcopy-gen

[English](README_EN.md)

为 Go 结构体和本地命名容器自动生成深拷贝方法，无需手写重复的复制代码。

## 功能特性

- 支持指针、切片、map、数组及嵌套组合，也支持类型别名和泛型类型。
- 保留 nil、非 nil 空容器、重复指针引用及通过指针形成的循环引用。
- 支持跨包类型，优先使用 `DeepCopyWithVisited` 共享访问记录，并兼容 `DeepCopy()`。
- 生成代码不使用运行时反射；基础类型容器和纯值对象使用优化的复制路径。
- 递归扫描子目录，按包输出 `deepcopy.dc.go`，自动避让声明名称冲突。

## 优势

- 减少手写复制逻辑，类型变更后重新生成即可，降低漏拷字段的风险。
- 生成普通 Go 代码，可直接审查、调试并随项目编译检查。
- 无需反射或序列化往返，基础容器和纯值对象走直接复制路径。

## 安装

需要 Go 1.21 或更高版本，并确保 Go 工具安装目录已加入 `PATH`。

```sh
go install github.com/451008604/deepcopy-gen@latest
```

## 使用

在目标项目中执行：

```sh
# 为指定目录及子目录生成复制方法
deepcopy-gen ./models

# 预览生成结果，不写入文件
deepcopy-gen -dry-run ./models

# 查看工具版本
deepcopy-gen -version
```

目录通过位置参数指定，选项必须放在目录之前。`-dir`、`-v` 已移除；使用 `-h` 查看帮助。

版本优先使用 Go 构建信息中的模块版本；没有模块版本时显示 `dev`，并在可用时附带 Git 修订号及修改状态。

生成后调用对象的 `DeepCopy()`：

```go
cloned := original.DeepCopy()
```

需要在多个根对象之间保留共享指针时，向它们的 `DeepCopyWithVisited` 传入同一张访问记录表。生成代码依赖本模块的 `deepcopy` 包，可运行 `go mod tidy` 整理依赖，再用 `go test ./...` 验证。

## 弊端与限制

- **不是任意对象的完整深拷贝**：接口动态值、无复制方法的泛型参数，以及无复制方法的外部类型可能仍共享内部数据。
- **不复制运行时资源**：函数、channel、`unsafe.Pointer` 保留原身份，锁等资源不在安全复制保证内。
- **引用关系有边界**：map 键保持原值；不保证切片底层数组的重叠关系及 map/slice 自身形成的无指针环。
- **语法与构建有限制**：不支持点导入、cgo 类型、泛型别名及无法展开的外部类型再定义；按当前构建环境生成，没有自定义 build tags 参数。
- **需要维护生成文件**：类型变更或目标构建环境变化后应重新生成，并编译验证；不要手动修改 `deepcopy.dc.go`。

详细支持范围、复制边界和测试说明见 [SUPPORT.md](SUPPORT.md)。
